Mã vạch mẫu

Mở ảnh trên máy tính hoặc in rõ trên giấy rồi quét bằng điện thoại. Chọn ảnh đúng chế độ ứng dụng đang dùng; mã mẫu chỉ tìm được khi sản phẩm tương ứng có trong danh mục.

Mười mã API dùng kho mẫu của server (profile demo và mật khẩu được cung cấp). Hai mã demo dùng dữ liệu riêng trong trình duyệt. Giữ nguyên toàn bộ chuỗi, kể cả số 0 ở đầu. Đây là mã CODE 128; không đổi sang EAN-13.
